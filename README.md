## Featured Projects

### White Sox Pitcher Command & Deception
Capstone project completed in collaboration with the Chicago White Sox to quantify pitcher command and deception using biomechanics and pitch outcome data.

**Highlights**
- Cleaned and modeled 400,000+ pitches from the 2024 MLB season
- Developed command and deception metrics using Gaussian Mixture Models and XGBoost
- Built Graph Neural Networks to identify biomechanical indicators of deception
- Awarded **Best in Show** at the University of Chicago MSADS Capstone Showcase

➡️ **Repository:**  
https://github.com/kdfischer4/white-sox-pitcher-command-deception
